# Состояние реализации

Актуальные требования — docs/requirements.md. Базовые клиент и сервер универсальны; Moodle UI, вход и маршруты интеграции вынесены в отдельные проекты. Клиентские пакеты подписаны, серверные устанавливаются администратором. Сборка Moodle-комплекта включает собственный runtime сервера и общий браузерный клиент. Данные экземпляра вынесены в Moodle dataroot; обычная серверная публикация не включает Moodle-модули.

Интерфейс общий для Avalonia desktop/Android/browser. Смайлики отключены, Material используется только для UI. Цвет аватарки выбирается в общей C#-библиотеке по ID/типу из 32 цветов. Проверены стабильность, распределение последовательных ID и контраст текста.

Проверки протокола покрывают переписку, права, сессии, ringing, синхронизацию Moodle, одноразовые переходы, календарный callback и реальную загрузку подписанной DLL. UI рендерится в узкой и широкой компоновке. Полный прогон — tests/run_checks.py.

Ограничения: настоящий Moodle ещё не прошёл установочные испытания; API-стенд не подтверждает совместимость его тем/версий. В native-клиентах медиа пока открывается через браузерный мост. SFU отсутствует, используется mesh с ограничением участников; фоновые push закрытого приложения не реализованы. Android APK собирается, но реальное устройство не проверялось. Это не следует считать полностью завершённым продуктом.
